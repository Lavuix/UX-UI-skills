# Changelog

Все заметные изменения Design Kit фиксируются здесь.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/): `MAJOR.MINOR.PATCH`.

Что версионируем этим файлом: **содержимое кита** — правила (`ux-lab/rules/`),
токены (`ux-lab/foundation/`), плейбук, шаблоны и база лучших практик.
Версию держим в файле [`VERSION`](VERSION).

> Не путать с **версионированием дизайна**: историю самих макетов ведёт оркестр
> в `CHANGELOG-DESIGN.md` внутри проекта (генерируется агентом Chronicler). См.
> [`RUNNING.md`](RUNNING.md).

## Когда какую цифру двигать

- **MAJOR** — несовместимое изменение процесса: переименование/удаление разделов
  спеки, ломающее старые спеки; смена структуры папок; замена Definition of Done.
- **MINOR** — обратно совместимое пополнение: новый паттерн в `best-practices/`,
  новое правило в `rules/`, новая фаза плейбука, новые токены.
- **PATCH** — правки без смены смысла: опечатки, уточнения формулировок, битые ссылки.

Правило: любое изменение в `ux-lab/` или `specs/` → строка в этот файл +
поднятая версия в `VERSION` в том же коммите.

## [1.22.0] — 2026-08-13

### Added
- Паттерн `bound-variable-paint-batch-size.md`: `setBoundVariableForPaint`,
  вызванный много раз подряд на один переменный цвет в одном скрипте Figma,
  молча теряет заданную прозрачность у части присвоений — держать партии
  ~5–9 присвоений за вызов и проверять `fills[i].opacity` после.
- В `table.md` зафиксировано конкретное решение по заливке уровней
  вложенности: один токен `background/secondary-b`, шаг прозрачности 5% на

## [1.21.0] — 2026-08-13

### Added
- Компонент `Table` задокументирован в каталоге (`components/table.md`,
  `components/INDEX.md`): собственные Table Cell (слот-ячейка с состояниями) и
  Group Actions Bar + переиспользованные атомы кита (CheckboxSquare, Tag,
  Userpic, Action Button, Pagination, Scroll, Empty Content).
- В `table.md` зафиксированы обязательные правила вложенности (tree-таблица):
  единый триггер раскрытия, свёрнуто по умолчанию, глубина ≤ 2–3 уровней,
  тройная индикация уровня (отступ + заливка + направляющая), агрегат в
  свёрнутой строке, сортировка/фильтрация внутри группы, каскадный выбор с
  indeterminate у родителя, действия не смешиваются между уровнями.

## [1.20.0] — 2026-08-13

### Added
- Паттерн `slot-cell-variant-states.md`: один Figma-слот на группу вариантов
  (напр. один Size), а не на каждый вариант State отдельно — иначе переключение
  состояния теряет контент слота, а `combineAsVariants` на клонах со слотом

  существующих инстансах.
