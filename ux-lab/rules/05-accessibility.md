# Доступность (WCAG)

Доступность — не «для инвалидов», а для всех: при ярком солнце, усталости, с
трекпадом. Базис — принципы **POUR**: Perceivable, Operable, Understandable,
Robust (воспринимаемо, управляемо, понятно, надёжно). Целевой уровень — **AA**.

## Конкретные пороги

**Контраст (яркостный)**
- Обычный текст: **≥ 4.5:1**.
- Крупный текст (≥ 24px, или ≥ 19px bold): **≥ 3:1**.
- Иконки и границы UI-элементов, несущие смысл: **≥ 3:1**.

**Размер целей**
- Минимум **24×24 px** (WCAG 2.2, AA). Рекомендуемо **44×44** (комфорт для пальца).
- Кликабельные элементы не должны слипаться — между ними отступ.

**Клавиатура и фокус**
- Всё, что доступно мышью, доступно с клавиатуры.
- Порядок фокуса логичен; фокус **виден** (заметная обводка).
- Нет «ловушек фокуса» (из модалки можно выйти клавиатурой).

**Цвет и смысл**
- Смысл никогда не передаётся **только** цветом. Статус = цвет **+** текст/иконка.
  (В разобранном макете статусы дублированы подписью — это правильно.)

**Движение и время**
- Уважай `prefers-reduced-motion`; не полагайся на анимацию для передачи смысла.
- Не ставь жёстких таймаутов без возможности продлить.

**Текст и структура**
- Реальный текст, а не картинки текста.
- Семантика: заголовки, метки полей, alt у смысловых изображений.
- Формы: у каждого поля видимая метка (не только плейсхолдер).

## Быстрая проверка

1. Прогони цвета через контраст-чекер (4.5:1 / 3:1).
2. Пройди экран только с клавиатуры — всё достижимо и фокус виден?
3. Обесцветь макет — смысл статусов/ошибок ещё читается?
4. Тач-цели ≥ 24px и не слиплись?

> Пример флага из реального файла: `content/tertiary` `#9CA3B6` на белом ≈ 2.6:1
> — не проходит 4.5:1. Такой цвет — только для крупного/декоративного текста.
