# Свод правил UI/UX

Собраны самые важные и наиболее цитируемые принципы, которые есть в индустрии.
«Всех, что есть в мире» — недостижимо и вредно; здесь — те, что дают наибольший
рычаг. Это **базовый слой**: универсальные правила. Поверх него Chronicler
оркестра наращивает **правила твоего проекта** (то, что подтвердилось именно у
тебя). При конфликте проектное правило с доказательствами побеждает универсальное.

## Definition of Done — чеклист перед сдачей макета

Быстрая проверка. Подробности — в файлах выше.

**Иерархия и внимание**
- [ ] С первого взгляда понятно, что главное на экране (одна доминанта).
- [ ] Похожее сгруппировано, разное разнесено (proximity + similarity).
- [ ] Ключевое действие выделено и попадает в удобную зону (Fitts).

**Ясность и когнитивная нагрузка**
- [ ] Число выборов на экране минимально необходимое (Hick).
- [ ] Используются знакомые паттерны, а не изобретённые (Jakob).
- [ ] Нет требования держать в голове данные с прошлых экранов (recognition > recall).

**Обратная связь и состояния**
- [ ] Есть ВСЕ состояния: default, loading, empty, error, disabled, success.
- [ ] Система всегда показывает свой статус; отклик < 400 мс (Doherty) или явный лоадер.
- [ ] Ошибки понятны: что случилось + как исправить.

**Доступность**
- [ ] Контраст текста ≥ 4.5:1 (крупный ≥ 3:1).
- [ ] Тач-цель ≥ 24×24 px (лучше 44×44), кликабельное не слипается.
- [ ] Всё доступно с клавиатуры, фокус виден; не только цветом передаётся смысл.

**Консистентность**
- [ ] Компоненты и токены из дизайн-системы, а не заново нарисованные.
- [ ] Термины, иконки, отступы единообразны с остальным продуктом.

**Копирайт и бренд-войс** (подробно — `07-voice-and-copy.md`)
- [ ] Кнопки — глаголы действия («Сохранить», а не «ОК»); ключевое — в начале.
- [ ] У текста есть полезное действие; нет модальных глаголов, страдательного
      залога, причастий, канцеляризмов, усилителей, скобок, риторических вопросов.
- [ ] «вы» со строчной; без лишних «пожалуйста»/«извините»; заголовки без точек и «!».
- [ ] Типографика TN Life: ёлочки, правильные тире, Ё, формат чисел/дат/денег, без капса.
- [ ] Тон: серьёзный, посередине офиц./повседневн., сдержанный, уважительный.

## Как это использует оркестр

UX Advisor обосновывает решения в том числе против этих правил, а на гейтах
ревью проще ловить нарушения по этому чеклисту. Подтверждённые в твоём проекте
уточнения Chronicler добавляет в `brain/`, не переписывая этот базовый слой.
