# Паттерн: выключай декоративные свойства компонента сразу при вставке

| Поле | Значение |
|------|----------|
| Категория | Компоненты |
| Уверенность | ⚪ допущение |
| Источник | HR-портал — заказ справок, 5 экранов, 2026-08-12/13 |
| Обновлено | 2026-08-13 |

## Практика

- **Делай:** сразу после вставки инстанса — выключай его декоративные булевые
  свойства, а не оставляй по умолчанию:
  - **Input / TextArea / MultiSelect / Calendar** — ведущую иконку, блок
    «Параметр», доп. иконки справа, открытый выпадающий список (`Param Menu` —
    без этого список остаётся раскрытым прямо на макете), нижнюю строку
    предупреждения (`Label War/Erorr`).
  - **Cell (2.0)** — подпись-подсказку (`Hint`) и галочку (`Check`), если в этом
    месте они не нужны (например, в пунктах бокового меню).
  - **Action Button** — `Left Icon` / `Right Icon`, если кнопка чисто текстовая
    (иначе по бокам текста остаются декоративные «+»).
  - **Header** — все семь пунктов навигации (`1 Item`…`7 Item`) и
    `MiniAppButton`/выпадающие кнопки, если на экране нет вкладок навигации.
  - **Готовые блоки с примерами данных** (например блок таблицы заявок) — найди и
    спрячь служебный инстанс/текст пустого состояния: он показывается поверх уже
    заполненных строк, если явно не выключить.
- **Избегай:** вставить компонент и сразу перейти к следующему, полагаясь на
  дефолтные значения — почти всегда что-то лишнее останется видно, и придётся
  возвращаться чинить уже на финальной проверке.

## Почему

На всех 5 экранах HR-портала после первой сборки на скриншоте всплывали одни и
те же вещи: у полей ввода — открытый выпадающий список с «Пункт 1…5» и лишние
иконки; у пунктов меню — ненужная подпись и красная галочка; у кнопок —
декоративные «+» по бокам текста; у блока таблицы — иллюстрация пустого
состояния под заполненными строками. Каждый раз это был отдельный проход-починка
по всему экрану. Выключение свойств сразу при вставке экономит минимум один
лишний проход на экран.

## Когда применимо

Компоненты Life-20_Kit_Light, у которых декоративные элементы вынесены в булевые
свойства инстанса. Не проверялось на изменившихся/новых версиях компонентов — у
них имена свойств могут отличаться, тогда стоит один раз подсмотреть точные ключи
свойств у самого компонента перед массовой вставкой.

## Пример

HR-портал — заказ справок, экраны 1–5.
