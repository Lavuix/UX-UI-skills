# Паттерн: компоненты — только из библиотеки кита, не из макетов

| Поле | Значение |
|------|----------|
| Категория | Компоненты / Сборка |
| Уверенность | ⚪ допущение |
| Источник | Сборка HR-портала (заказ справок), сессия 2026-08-13, замечание дизайнера |
| Обновлено | 2026-08-13 |

## Практика

- **Делай:** любой компонент на макете — всегда `search_design_system` →
  `importComponentByKeyAsync`/`importComponentSetByKeyAsync` из опубликованной
  библиотеки кита (`Life-20_Kit_Light` и смежные `Life-*`). Источник — только
  библиотека, никогда не сам макет.
- **Избегай:**
  - Не копируй и не «собирай на глаз» узел, похожий на компонент, если он найден
    внутри самого макета/шаблонного файла (например `Life-04_Templates`) — такие
    файлы смотрим только как образец раскладки (skeleton), компоненты из них не
    берём.
  - Если инстанс, который нашёлся на канвасе, выглядит как «слипшиеся» несколько
    смыслов в одном узле (например поле поиска + две кнопки внутри одного
    `InputSearch`) — это красный флаг: значит, взяли не тот источник. Разбери
    дерево (`findAll`), найди реальный атомарный компонент через
    `search_design_system` и пересобери отдельными инстансами.

## Почему

При сборке экрана «Справки» (шаблон SidePage) поле поиска в тулбаре оказалось
частью составного узла, в который были зашиты ещё две кнопки (сортировка и
фильтр) как скрытые дочерние инстансы — это не было видно по свойствам варианта,
только по разбору дерева. Дизайнер поправил вручную и сформулировал правило:
компоненты — только из кита. Данных/теста нет, это дисциплина по итогам одного
инцидента, поэтому уверенность ⚪.

## Когда применимо

- Работает всегда при сборке любого экрана оркестром/агентом-Строителем.
- НЕ распространяется на раскладку/skeleton — `ux-lab/foundation/templates/` и
  внешние шаблонные файлы (`Life-04_Templates`) по-прежнему легитимный источник
  структуры страницы, просто не источник самих компонентов.

## Пример

Figma `VmbFLLzl6A6IDw29Nf9C2v`, страница «HR-справки - 3.Справки», node `36:16926`
(до и после разбора на поле поиска + отдельную кнопку сортировки).
