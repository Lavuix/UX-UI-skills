# Паттерн: иконки Life-10_Icons — только «Outline Light», не «Outline Regular»

| Поле | Значение |
|------|----------|
| Категория | Компоненты / Иконки |
| Уверенность | ⚪ допущение |
| Источник | Сборка HR-портала (заказ справок), сессия 2026-08-13, замечание дизайнера |
| Обновлено | 2026-08-13 |

## Практика

- **Делай:** библиотека `Life-10_Icons` содержит ДВЕ параллельные страницы-набора
  символов: «Outlines Regular» и «Outlines Light» (файл `4deZmrS65qGmOEhRzjNFnS`,
  страницы `1:10` и `198:4973`). Для сайдменю/навигации и вообще для интерфейсных
  иконок в макетах кита — брать только **Light**. `search_design_system` отдаёт
  кандидатов из обеих страниц вперемешку под одинаковыми/похожими именами и не
  помечает, из какой они страницы — совпадение по имени НЕ гарантирует, что взят
  Light-вариант.
  - Где название уже однозначно light-специфичное (например «Help 1» vs просто
    «Help») — ориентируйся на такое имя.
  - Где имя одинаковое на обеих страницах (Document, Calendar, Settings, User,
    Chevron/Left) — импортируй все найденные `componentKey`-кандидаты, отрендери
    рядом и сверь со скриншотом реального символа со страницы `198:4973` в
    исходном файле, прежде чем выбирать.
  - Если для понятия вообще нет Light-версии (например «Documents» во
    множественном числе — только в Regular) — НЕ бери Regular-вариант. Ставь
    дефолтную light-иконку карандаша **Edit** (componentKey
    `963a14d75a8e6487b0ab24f6d89b90ba8504a597`) как безопасный fallback, даже если
    из-за этого один и тот же значок повторится в одном меню дважды.
- **Избегай:** не полагайся на визуальное «на глаз похоже» при мелком масштабе
  превью — Calendar-Regular и Calendar-Light различаются только галочкой внутри
  сетки и на маленьком скриншоте это легко пропустить.

## Почему

Первая сборка сайдменю HR-портала подобрала иконки по совпадению имени без
проверки страницы-источника — часть (Calendar, Document, стрелка «Свернуть»)
оказались из Regular, а не Light. Дизайнер визуально поймал несоответствие стиля
(«обычный outline, а не outline light») и указал точные страницы-источники в
файле библиотеки. Данных/теста нет — это дисциплина по итогам одного инцидента,
уверенность ⚪.

## Когда применимо

- Работает для любой иконки из `Life-10_Icons`, вставляемой в макет кита.
- Правило про конкретные проверенные пары (что light, что нет) справедливо
  ровно для перечисленных выше понятий на момент 2026-08-13 — состав библиотеки
  может измениться, сверку лучше повторять, а не полагаться только на этот список
  бессрочно.

## Пример

Figma `VmbFLLzl6A6IDw29Nf9C2v`, сайдменю на страницах «HR-справки - 1/4/5» —
до и после замены Calendar/Document/Chevron-Left на light-эквиваленты и Documents
(без light-варианта) на fallback-иконку Edit.
