# Библиотека персон — индекс

Переиспользуемые профили для агента `respondent`. **Перед прогоном загляни сюда** —
если подходящая персона уже есть, бери её; заводи новую, только если ни одна не
покрывает сегмент/сценарий задачи.

| Персона | Суть в одну строку | Файл |
|---------|--------------------|------|
| Новичок без опыта | Не знает продукт, читает подписи буквально, не спешит | `novice-no-experience.md` |
| Опытный и спешит | Знает продукт, идёт кратчайшим путём, пропускает подсказки | `expert-in-hurry.md` |
| Низкое доверие | Перепроверяет необратимые/платные шаги, ищет объяснение последствий | `low-trust.md` |
| Оператор линии (заводчанин) | Производство, новичок в цифре, боится ошибиться и получить разнос | `operator-linii.md` |
| Мастер участка | Производство, спешит, верит только своим цифрам участка | `master-uchastka.md` |
| Бухгалтер материальной группы | Финансы/офис, 1С-эксперт, любая ошибка в цифрах — её | `buhgalter-materialnoy-gruppy.md` |
| 1С-разработчик | ИТ, оценивает всё через призму 1С и архитектуру данных | `1c-razrabotchik.md` |
| Офисный сотрудник (логистика/продажи/маркетинг) | Офис, много систем в день, доверяет знакомым паттернам | `ofisny-sotrudnik.md` |
| DevOps инженер | ИТ, хоткеи вместо мыши, не доверяет без API | `devops-inzhener.md` |
| Системный администратор | ИТ, 20+ лет опыта, требует логи и настройки | `sistemny-administrator.md` |
| Безопасник (ИБ) | ИБ, смотрит глазами атакующего, не доверяет никому | `bezopasnik-ib.md` |
| Руководитель среднего звена | Руководство, 5 секунд на экран, нужны решения а не данные | `rukovoditel-srednego-zvena.md` |
| _[твоя персона]_ | … | `…` |

## Как пополнять

1. Скопируй `_TEMPLATE.md` → `<короткое-имя>.md`, заполни.
2. Добавь строку в таблицу выше.
3. Новую персону заводи, только если сценарий/сегмент задачи явно не покрыт
   существующими тремя — иначе библиотека раздувается дублями с разницей в оттенках.
