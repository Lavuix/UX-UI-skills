# Библиотека персон — индекс

Переиспользуемые профили для агента `respondent`. **Перед прогоном загляни сюда** —
если подходящая персона уже есть, бери её; заводи новую, только если ни одна не
покрывает сегмент/сценарий задачи.

| Персона | Суть в одну строку | Файл |
|---------|--------------------|------|
| Новичок без опыта | Не знает продукт, читает подписи буквально, не спешит | `novice-no-experience.md` |
| Опытный и спешит | Знает продукт, идёт кратчайшим путём, пропускает подсказки | `expert-in-hurry.md` |
| Низкое доверие | Перепроверяет необратимые/платные шаги, ищет объяснение последствий | `low-trust.md` |
| _[твоя персона]_ | … | `…` |

## Как пополнять

1. Скопируй `_TEMPLATE.md` → `<короткое-имя>.md`, заполни.
2. Добавь строку в таблицу выше.
3. Новую персону заводи, только если сценарий/сегмент задачи явно не покрыт
   существующими тремя — иначе библиотека раздувается дублями с разницей в оттенках.
