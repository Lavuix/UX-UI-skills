# 3. Оркестратор — сложный режим

Оркестр — цепочка агентов Claude Code, которая собирает Figma-макеты по задаче со
строгими проверками и паузами. Он **уже лежит в этом репозитории** (`.claude/`),
ставить и обновлять ничего не надо. Полное объяснение — в [`ОРКЕСТР.md`](../../ОРКЕСТР.md).

## Как запустить

Открой папку в Claude Code, напиши задачу или «привет» — Claude предложит 4 действия.
Выбери **пункт 4 (Оркестратор)** или напиши «оркестр». Всё по-русски; дизайн-система
(Life-20_Kit) считается на месте всегда.

## Цепочка агентов

Scout (проверка дизайн-системы) → Spec Analyst (план + пауза на твоё решение) →
UX Advisor (обоснование против прецедентов) → Builder (пишет в Figma) → Respondent
(панель, слепой A/B) → финальная сверка + пауза → Chronicler (журнал → правила).
Два места, где решение принимаешь ты (гейты).

Дополнительно есть режимы `/concept` (визуальные направления для нового продукта) и
`/foundation` (дизайн-система из референса) — нужны редко, только для совсем нового
продукта с другой дизайн-системой. И `/concept`, и шаг UX Advisor умеют предложить
дешёвую синтетическую панель (**claude-persona**, см. `4-testing.md`) до сборки —
как доп. сигнал для выбора между направлениями/формулировками, не замену решению
дизайнера.

## Как ложится наш ux-lab

Наши файлы — вход и база для оркестра: `foundation/tokens.md` — источник стиля,
`rules/` — чеклист для гейтов, `best-practices/` — паттерны, которые Chronicler
предлагает переложить в память проекта (`brain/`).
