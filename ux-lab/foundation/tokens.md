## ⚠️ Замечания к системе (для фикса на уровне токенов)

1. **`content/accent` = `Red/60` = `#E11B11`.** Бренд-акцент совпадает с
   деструктивным статусом «Отменена». Развести: завести отдельный
   `content/danger`, чтобы красный ошибки не путался с красным бренда.
2. **`content/tertiary` `#9CA3B6` не проходит WCAG AA** (~2.6:1) для обычного
   текста. Использовать только для крупного/декоративного, либо затемнить.
3. **Ссылки.** Если ссылки/№ красные — они конкурируют с семантикой ошибки и
   недобирают контраст в мелком кегле; для действий уже есть синий `#1284FF`.
