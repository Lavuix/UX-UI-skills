## Назначение

Единичный выбор из выпадающего списка. Поле со значением и списком опций,
опционально — с поиском.

## Оси вариантов

- **State:** Empty · EmptyHovered · EmptyPressed · Filled · FilledHovered · FilledPressed · Disabled
- **Error:** No · Yes
- **Search:** No · Yes (со строкой поиска по опциям)

## Форма и размеры

Поле ≈ 414×141 (с подписью). Пустое ниже, раскрытый список — оверлеем поверх контента.

## Правила применения

- Один выбор из списка; для нескольких — MultiSelect.
- **Search = Yes** — когда опций много (длинные справочники).
- Выбранное значение читаемо; недоступные опции — Disabled.
- Ошибка — с пояснением по бренд-войсу.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
