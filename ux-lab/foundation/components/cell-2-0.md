## Назначение

Строка списка/меню — базовый ряд, из которого собираются списки, настройки,
навигация и таблицы. Тип задаёт содержимое строки.

## Оси вариантов

- **Type:** User · Navigation · Select · Switch · Divide
- **Size:** S · M
- **Align:** Middle · Top (выравнивание контента по вертикали)
- **State:** Enabled · Hovered · Pressed · Disabled

## Форма и размеры

Ширина — по контейнеру (в спецификации ≈ 360). Высота ряда ≈ 48–63 в зависимости
от типа и размера. Разделитель (`Divide`) ниже.

## Правила применения

- **User** — строка с пользователем/аватаром; **Navigation** — переход дальше;
  **Select** — выбор значения; **Switch** — переключатель; **Divide** — разделитель.
- **Align = Top** — когда в строке многострочный контент; иначе **Middle**.
- **Size** согласуем с плотностью списка (S — компактные списки/таблицы, M — обычные).
- Разделитель `Divide` — только между группами, не после каждой строки.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
