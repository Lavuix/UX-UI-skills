## Назначение

Левая навигационная панель приложений (rail): переключение между сервисами
экосистемы, с индикатором и выпадающим меню.

## Оси вариантов

- **Кнопка приложения (`.apps_buttons`):** Active = no · yes × State = Enabled · Hovered · Pressed · Disabled
- **Индикатор запуска (`.launch_indicator`):** Active = Yes · No
- **Меню (`.sidebar_menu`)** — раскрывающийся список.

## Форма и размеры

Ширина панели 64 (rail), высота во весь экран; кнопка приложения 40×40.

## Правила применения

- Один активный сервис (Active = yes) за раз.
- `launch_indicator` — точка активности/запущенного сервиса.
- `sidebar_menu` — по наведению/клику для доп. пунктов.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
