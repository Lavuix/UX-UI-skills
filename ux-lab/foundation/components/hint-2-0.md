## Назначение

Подсказка/тултип рядом с элементом: пояснение, справка, короткая контекстная
информация во всплывающем блоке.

## Оси вариантов

- **Type:** Alot · Mine · OnlyText (объём наполнения: развёрнутый / компактный / только текст)
- **Color:** Dark · Light (тёмная и светлая подложка)

Наполнение — через слот `.ContentLight`: Alot · OnlyText · Mine.

## Форма и размеры

Блок с хвостиком-указателем; ширина/высота под контент (от ≈177×85 у `OnlyText`
до ≈342×200 у `Alot`).

## Правила применения

- **OnlyText** — для одной короткой мысли; **Alot** — когда нужно объяснить подробно.
- **Color** выбираем по контрасту с фоном под подсказкой.
- Подсказка не заменяет понятный интерфейс — только дополняет.
- Текст — по бренд-войсу: коротко, с пользой, без «воды».
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
