## Назначение

Карточка-контейнер для блока содержимого: элемент списка, выбираемый объект,
кликабельный блок. Держит единый ритм списков и рабочих зон.

## Оси вариантов

- **Type:** Primary · Secondary
- **Active:** No · Yes (выбранное/активное состояние карточки)
- **State:** Default · Hovered · Pressed · Disabled

Наполнение — через вложенный слот `.Content`: **Simple · Rich 1 · Rich 2**.

## Форма и размеры

Базовая карточка ≈ 359×74. Высота растёт под наполнение (`Rich` варианты выше).
Отступы и ритм — по токенам пространства, не произвольными пикселями.

## Правила применения

- Одна карточка = один смысловой блок; карточка кликабельна как целое.
- **Active = Yes** — для выбранного элемента (в списках с выбором), не для акцента.
- **Primary / Secondary** — визуальная важность блока в потоке.
- Наполнение берём из слота `.Content` (Simple для короткого, Rich — для плотного).
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
