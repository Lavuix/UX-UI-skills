## Назначение

Ярлык/метка: статус, категория, тип — короткое значение в наборе элементов.

## Оси вариантов

- **State:** Enabled · Hovered · Pressed · Disabled
- **Filled:** No · Yes (контурный / залитый)
- **Size:** S · M · L

## Форма и размеры

Высота ≈16 (S) / 28 (M) / 32 (L); ширина по тексту.

## Правила применения

- Одно понятное значение на тег; без длинных объяснений.
- **Filled = Yes** — для акцентных статусов; No — нейтральные метки.
- Интерактивный тег (Hovered/Pressed) — только если по нему есть действие.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
