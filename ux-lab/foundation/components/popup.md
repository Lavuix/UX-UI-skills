## Назначение

Модальное окно поверх контента: подтверждение, короткая форма, важное сообщение.

## Оси вариантов

- **Type:** Desktop · Mobile

## Форма и размеры

Desktop ≈722 по ширине, Mobile ≈375; высота по содержимому. Открывается по центру
с затемнением фона.

## Правила применения

- Для действий в попапе: **Primary справа, Secondary рядом** (см. Action Button).
- Один вопрос/задача на попап; закрытие — по действию или клику вне/Esc.
- Не носит длинный контент — для этого отдельный экран.
- Текст — по бренд-войсу: заголовок без точки, суть сразу.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
