## Назначение

Множественный выбор из списка: несколько значений, показанных тегами в поле, с
опциональным поиском по вариантам.

## Оси вариантов

- **State:** Empty · EmptyHovered · EmptyPressed · Filled · FilledHovered · FilledPressed · Disabled · Input
- **Error:** No · Yes
- **Search:** No · Yes (со строкой поиска по опциям)

Выбранные значения — теги (`.Tags`): Type = Fix · String · NoFix.

## Форма и размеры

Поле ≈ 414 по ширине; высота растёт под количество выбранных тегов (от ≈141 пустое
до ≈227 с тегами и поиском).

## Правила применения

- Выбранные значения показываем тегами; **Search = Yes** — когда опций много.
- **Fix** — неудаляемый тег, **NoFix** — с удалением, **String** — простой текстовый.
- Для единичного выбора берём Select, не MultiSelect.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
