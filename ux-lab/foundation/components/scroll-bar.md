## Назначение

Полоса прокрутки для областей с переполнением контента.

## Оси вариантов

- **Position:** Vertical · Horizontal
- **Property (состояние):** Enabled · Hovered · Pressed · Disabled

## Форма и размеры

Толщина ползунка 12; длина — по контенту (верт. ≈74 в примере, гориз. ≈71).

## Правила применения

- Появляется при переполнении области; не подменяет пагинацию для длинных списков.
- Hovered/Pressed — обратная связь при перетаскивании.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
