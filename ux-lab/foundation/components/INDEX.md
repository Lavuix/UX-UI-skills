# Каталог компонентов «Life»

Описания компонентов дизайн-системы. Одна карточка = один компонент (в Figma — одна
страница = один компонент). Статус берём из названия страницы в Kit_Light.

## Легенда статусов

| Значок | Значение | В каталог? |
|--------|----------|-----------|
| ✅ | готов | **да** — описываем |
| ? | не финализирован | **да** — описываем |
| 🔍 | на ревью | **да** — описываем |
| (In progress) | в работе | **нет** — пропускаем |

**Правило:** берём все компоненты, **кроме `(In progress)`**. У не-`✅` в карточке
помечаем статус, чтобы помнить, что решение ещё может измениться.

## Как пополнять

1. Скопируй `_TEMPLATE.md` → `<название>.md`, заполни (описание, оси, применение —
   без дублирования привязок токенов).
2. Обнови строку в реестре: статус + ссылка на карточку.
3. Не-`✅` не заносим как готовые.

> Каталог описывает **поведение и применение**. Значения цветов/типографики/радиусов
> живут в самом компоненте в Figma (см. [`../tokens.md`](../tokens.md)). Текст в
> компонентах — по [`../../rules/07-voice-and-copy.md`](../../rules/07-voice-and-copy.md).
