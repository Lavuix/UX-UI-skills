# Каталог компонентов «Life»

Описания компонентов дизайн-системы по слоям атомарного дизайна. Одна карточка =
один компонент (в Figma — одна страница). Правила ведения — в [`README.md`](README.md).

## Легенда

**Статус (из названия страницы):** `✅` готов · `?` не финализирован · `🔍` на ревью ·
`(In progress)` — **не берём**.
**Сверка:** ✔ сверено с Figma · ⚠ черновик (ещё не описан по Figma).

Берём все компоненты, **кроме `(In progress)`**.
