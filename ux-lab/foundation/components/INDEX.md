# Каталог компонентов «Life»

Описания компонентов дизайн-системы. Одна карточка = один компонент; статус
берём из Figma (эмодзи в названии страницы).

**Правило:** компоненты со статусом **In progress берём только когда они готовы** —
в макеты идут лишь `✅`.

| Компонент | Статус | Карточка |
|-----------|--------|----------|
| Action Button | ✅ | [`action-button.md`](action-button.md) |
| _[следующий]_ | 🚧 / ✅ | `…` |

## Как пополнять

1. Скопируй `_TEMPLATE.md` → `<название>.md`, заполни (описание, оси, применение —
   без дублирования привязок токенов).
2. Добавь строку в таблицу выше со статусом.
3. In progress не заносим как готовые.

> Каталог описывает **поведение и применение**. Значения цветов/типографики/радиусов
> живут в самом компоненте в Figma (см. [`../tokens.md`](../tokens.md)).
