## Назначение

Многострочное поле ввода: комментарии, описания, длинный текст.

## Оси вариантов

- **State:** Empty · EmptyHovered · EmptyPressed · Typed · Filled · FilledHovered · Disabled
- **Error:** No · Yes

## Форма и размеры

Ширина ≈414; высота ≈206 (выше, чем Input), с возможностью роста под текст.

## Правила применения

- Для длинного ввода; для короткого — Input.
- Лейбл и подсказка объясняют, что писать; при лимите — счётчик символов.
- Ошибка — с пояснением по бренд-войсу.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
