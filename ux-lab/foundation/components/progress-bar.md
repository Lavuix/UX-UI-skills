## Назначение

Индикатор прогресса: линейный, в т.ч. сегментированный (шаги).

## Оси вариантов

- **ProgressBar (сегментированный):** Kind = default, Quantity = 1…12 (число сегментов)
- **ProgressBarMain (сплошной):** Active = On · Off × Kind = Progress · Default

## Форма и размеры

Высота линии 4; ширина по контейнеру (в примере ≈336).

## Правила применения

- **Сегментированный** (Quantity) — для пошаговых процессов (шаг N из M).
- **Сплошной** (Progress) — для непрерывного прогресса (загрузка, заполнение).
- **Active = Off** — неактивная/фоновая дорожка.
- Прогресс сопровождаем понятным статусом текстом, если процесс долгий.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
