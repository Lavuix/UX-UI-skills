## Назначение

Постраничная навигация по спискам и таблицам.

## Оси вариантов

- **Size:** Large · Medium
- **Страница (`.Page`):** Selected = No · Yes × Size = Large · Medium × State = Active · Hovered · Pressed · Disabled

## Форма и размеры

Ячейка страницы: Large 48×53, Medium 40×44.

## Правила применения

- **Selected = Yes** — текущая страница (одна активная).
- **Size** согласуем с плотностью таблицы (Medium — компактные таблицы).
- Для бесконечных списков предпочитаем подгрузку, пагинацию — для чётких наборов.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
