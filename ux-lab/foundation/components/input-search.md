## Назначение

Поле поиска: ввод запроса с иконкой поиска и очисткой. Разновидность Input под
фильтрацию списков и таблиц.

## Оси вариантов

- **State:** Empty · EmptyHovered · EmptyPressed · Typed · Filled · FilledHovered · Disabled
- **Error:** No · Yes
- **Size:** M · S

## Форма и размеры

Size M ≈ 414×141 (с подписью), Size S ≈ 414×70 (компактное, для панелей и таблиц).

## Правила применения

- **Size S** — в тулбарах, над таблицами, рядом с фильтрами; **M** — в формах.
- Иконка очистки появляется при заполнении; поиск запускается по вводу/enter.
- Пустой результат — через компонент Empty Content.
- Компонент берём из библиотеки как есть — привязки токенов/стилей живут внутри
  него, руками не трогаем.
