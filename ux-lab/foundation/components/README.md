# Каталог компонентов — как вести (протокол)

Каталог описывает компоненты дизайн-системы «Life» по слоям **атомарного дизайна**
и по единому шаблону. Источник правды — Figma. Ниже — жёсткие правила заполнения
(для человека и для агента `/foundation`).

## Слои (atomic design)

- **Атомы** — неделимые: Action Button, Controls (Checkbox/Radio/Switch), Tag,
  Userpic, Progress Bar, Skeletons, иконки.
- **Молекулы** — из атомов: Input, InputDate, InputSearch, Select, MultiSelect,
  Cell (2.0), Hint, Breadcrumbs, Pagination, Tabs, TextArea, Dropdown, SnackBar.
- **Организмы** — из молекул: Cards, Header, Toolbar, Sidebar, Popup, Bottomsheet,
  Empty Content / 404, System, Mail, Floating Button.
- **Шаблоны** — компоновки экранов из организмов → каталог [`../templates/`](../templates/)
  (по карточке на темплейт: что за экран, из чего собран, когда применять).
- **Страницы/примеры** — конкретные применения; на них ссылаемся из карточек.

Слой указываем в шапке карточки (поле «Уровень»).

## Правила заполнения карточки (важно — не выдумывать)

1. **Источник правды — страница компонента в Figma.** Оси вариантов и состояния
   берём из имён вариантов (`Type=…`, `Size=…`, `State=…`), **не придумываем**.
2. **Нет доступа к странице → запроси у заказчика ссылку** (в Figma: правый клик по
   странице → Copy link to page). Не заполняй наугад.
3. **Ссылку получить нельзя / не достучаться → бери за основу страницу-пример
   применения**, если она есть в файле. Опиши по примеру и **пометь**: «сверено по
   примеру использования, не по мастер-компоненту».
4. **Никогда не заполняй оси/состояния догадками.** Честный черновик со статусом
   «не сверено» лучше правдоподобной выдумки.
5. **Отмечай сверку** в шапке: `✔ сверено с Figma (node …)` либо
   `⚠ черновик — не сверено`.
6. **Привязки токенов не дублируем** — они живут в самом компоненте (см.
   [`../tokens.md`](../tokens.md)).
7. **Текст** в компоненте — по [`../../rules/07-voice-and-copy.md`](../../rules/07-voice-and-copy.md).

## Статусы компонента (из названия страницы Kit_Light)

Берём все, **кроме `(In progress)`**. `✅` — готов; `?` — не финализирован; `🔍` —
на ревью (в карточке помечаем, что решение может измениться). См. [`INDEX.md`](INDEX.md).

## Как пополнять

1. Скопируй [`_TEMPLATE.md`](_TEMPLATE.md) → `<название>.md`, заполни по правилам выше.
2. Обнови строку в [`INDEX.md`](INDEX.md): статус + сверка + ссылка.
3. Шаблоны из файла Life-04_Templates описывай в `../templates/` по тому же принципу.
