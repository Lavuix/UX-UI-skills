# Каталог шаблонов (Templates) — как вести

Шаблоны — верхний слой атомарного дизайна: **экраны, собранные из организмов и
компонентов**. Источник — Figma-файл **Life-04_Templates** (`g3P4HUG0FGh62FZHQKQW7l`).

Одна карточка = одна страница/экран (или семейство близких состояний одного экрана).
Правила — те же, что для компонентов (см. [`../components/README.md`](../components/README.md)):

1. Оси/состояния и состав — **только из Figma**, не выдумываем.
2. Нет доступа к странице → просим ссылку (Copy link to page); никак → описываем по
   странице-примеру, помечая это.
3. Отметка сверки в шапке (`✔ сверено с Figma (node …)`).
4. Значения токенов не дублируем — они внутри компонентов.

## Что фиксируем в карточке шаблона

- **Назначение** — какой это экран и какую задачу закрывает.
- **Раскладка** — общая структура (например: Sidebar + Header + Sidemenu + Content + Right panel).
- **Из чего собран** — список компонентов/организмов (ссылки на карточки в `../components/`).
- **Состояния/варианты** — заполнено/пусто/ошибка и т.п., если представлены.
- **Когда применять** — для каких сценариев брать этот шаблон.

Реестр — в [`INDEX.md`](INDEX.md). Шаблон карточки — [`_TEMPLATE.md`](_TEMPLATE.md).
