# Foundation — раскладка приложения (App Shell, «острова»)

Интерфейс «Life» построен по принципу **островов (island layout)**: рейл, верхнее
меню и рабочие панели — это **отдельные контейнеры со скруглением и зазорами** от
краёв страницы и друг от друга, а не блоки, приклеенные к краям экрана.

Замерено по экрану `Life-04_Templates` node `1:5924` (десктоп 1920×1080).

## Структура (десктоп)

```
┌──────────────────────────────────────────── страница 1920×1080 (фон-подложка) ─┐
│  ~8                                                                             │
│  ┌────┐ 12 ┌──────────────────────────────────────────────────────────────┐   │
│  │    │    │  Header (верхнее меню) — остров, высота 56                     │   │
│  │ S  │    ├──────────────────────────── 16 ─────────────────────────────  │   │
│  │ i  │    │  ┌─────────┐ 16 ┌───────────────────┐ 16 ┌──────────────────┐ │   │
│  │ d  │    │  │ Sidemenu│    │   Рабочая область │    │  Правая панель   │ │   │
│  │ e  │    │  │  320    │    │   (форма/таблица) │    │  действий 360    │ │   │
│  │ b  │    │  │ остров  │    │      остров       │    │      остров      │ │   │
│  │ a  │    │  └─────────┘    └───────────────────┘    └──────────────────┘ │   │
│  │ r  │    │                                                               │   │
│  │ 64 │    └──────────────────────────────────────────────────────────────┘   │
│  └────┘                                                                         │
└────────────────────────────────────────────────────────────────────────────────┘
```

## Размеры и зазоры

| Элемент | Значение | Токен |
|---------|----------|-------|
| Отступ от краёв страницы | ~8 | `--space-8` |
| Ширина рейла (Sidebar) | 64 | — |
| Зазор рейл → контент | 12 | `--space-12` |
| Высота верхнего меню (Header) | 56 | — |
| Зазор Header → рабочая область | 16 | `--space-16` |
| Ширина Sidemenu | 320 | — |
| Ширина правой панели действий | 360 | — |
| Зазоры между рабочими островами | 16 | `--space-16` |

Скругление островов — через радиус-токены (`--radius-*`), фон-подложка страницы —
через токены темы (`background/*`).

## Правила

- **Панели — острова.** Sidebar, Header и рабочие блоки не приклеиваем к краям —
  между ними и краями страницы всегда зазор (см. таблицу), углы скруглены.
- **Зазоры — только токенами** `--space-*` (8/12/16), не произвольными числами.
- **Рейл слева отдельно от верхнего меню:** Header — остров в колонке контента, он
  не заходит на рейл; рейл — самостоятельный остров во всю высоту.
- **Три рабочие зоны** типового экрана: Sidemenu (навигация раздела, 320) →
  центральная область (форма/таблица) → правая панель действий (360). Панель справа
  держит главное действие (Primary — см. [`components/action-button.md`](components/action-button.md)).
- Цвета островов и подложки — **только токены темы**, переключение Light/Dark работает само.

## Как ложится на шаблоны

Все экраны в [`templates/`](templates/) собраны по этой раскладке: Sidebar + Header +
(Sidemenu · контент · правая панель). Отличается только наполнение центральной зоны
и правой панели.
