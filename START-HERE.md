# 🟢 START HERE — инструкция для новичка

Это набор правил и инструментов для дизайна в системе **Life-20_Kit**. Claude читает инструкции и токены из этого репозитория, а затем помогает собирать экраны в Figma, предварительно оценивать их с помощью синтетических персонажей или делать HTML-прототипы.

Это не отдельная программа: для режимов Figma нужен Claude Code с подключённым Figma и открытым файлом, куда нужно добавить макет.

## Выбери, что нужно сделать

В начале работы Claude покажет меню из шести действий. Можно выбрать номер или сразу описать задачу.

| № | Действие | Когда выбирать |
|---|---|---|
| **1** | Использовать макет в Figma как основу | Есть ссылка на экран-образец, по которому нужно собрать или изменить макет. |
| **2** | Сделать экран или задачу | Нужно быстро собрать экран или небольшую задачу в Figma. |
| **3** | Собрать компонент | Нужно добавить или изменить компонент в Figma. |
| **4** | Запустить оркестратор | Большая или важная функция: сначала план и согласование, затем сборка и проверки с ещё одним согласованием. |
| **5** | Предварительно проверить готовый макет | Нужно получить прогноз возможных затруднений по картинке или ссылке на Figma. Это проверка на **синтетических персонажах**, а не исследование с реальными пользователями. |
| **6** | Собрать HTML-прототип | Нужен кликабельный прототип в виде отдельного HTML-файла, вне Figma. |

Обычно для небольшого экрана подходят пункты **1–3**. Пункт **4** используй для сложной функции, где важны подробный план и проверки. Пункты **5** и **6** — отдельные режимы: исследование не меняет макет, а HTML-прототип не создаёт фреймы в Figma.

## Что настроить один раз

1. Подключи Figma в настройках Claude Code: **Settings → Connectors → Figma → Connect**.
2. Открой в Figma файл, куда нужно добавить макет. Режимы **1–4** создают фреймы в активном файле.
3. Для режима **5** подготовь картинку макета или ссылку на Figma. Для режима **6** подключение Figma не требуется.

## Как открыть набор

Склонируй репозиторий и открой его как папку проекта в Claude Code:

```bash
git clone https://github.com/Lavuix/UX-UI-skills.git
cd UX-UI-skills
claude
```

Можно также открыть эту папку в VS Code с расширением Claude Code. После запуска опиши задачу или выбери действие из меню. Например, для нового экрана выбери **2** и напиши: `сделай экран заказа справки с места работы`.

Для оркестра выбери **4**, напиши «оркестр» или запусти `/start`. Для обычной сборки выбери **1–3** и опиши задачу.

## Как проходит работа

Для пунктов **1–3** Claude уточнит задачу и соберёт макет в активном файле Figma. После этого можно попросить добавить состояния, например ошибку или пустой экран, или поправить конкретные элементы.

Для пункта **4** оркестратор сначала покажет план экранов и вопросы по задаче. После твоего подтверждения команда соберёт макеты, сверит их с планом и покажет результат на финальное согласование. Оркестратор не должен объявлять задачу завершённой, пока фреймы не появились в Figma.

Для пункта **5** Claude покажет возможные проблемы макета и сохранит отчёт. Такой прогон помогает найти вопросы для дальнейшей проверки, но не заменяет тест с реальными пользователями: поведение, время и эмоции реальных людей здесь не измеряются.

Для пункта **6** Claude соберёт самодостаточный HTML-файл, который можно открыть в браузере. Figma-макет при этом не меняется.

## Нашёл полезное решение?

Если в работе обнаружилось неочевидное решение или ограничение, Claude может предложить оформить его как паттерн в `ux-lab/best-practices/patterns/`. Проверь текст и уровень уверенности. Непроверенное решение отмечай как допущение; не выдавай его за подтверждённое исследование.

Изменения в `ux-lab/` и `specs/` сопровождаются записью в `CHANGELOG.md` и обновлением `VERSION`. Подробности — в [`CLAUDE.md`](CLAUDE.md).

## Если что-то не работает

- **Figma-макет не появляется** — проверь подключение Figma и активный файл. Если проблема осталась, сообщи Claude; не считай текстовый план готовым макетом.
- **Нет доступа к Figma** — для проверки готового экрана пришли изображение, а для прототипа выбери пункт **6**.
- **Хочешь остановить или изменить направление** — напиши «стоп», «отмени» или уточни, что нужно переделать.
