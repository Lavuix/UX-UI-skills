# Прототипы

Результаты режима **HTML-прототип** (пункт 6 в главном меню кита, см. корневой
`CLAUDE.md` и `.claude/skills/html-prototype/SKILL.md`).

Каждая задача — своя папка `<короткое-название>/` с самодостаточным `index.html`
(стиль и токены — как в Figma-макетах кита, см.
`ux-lab/foundation/tokens/tn-life.css`). Открывается двойным кликом в браузере,
без сборки и без интернета.
